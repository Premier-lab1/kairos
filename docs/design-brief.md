# Kairos — дизайн-бриф (черновик)

Собран 18.10.2026 из референсов в папке проекта и комментария заказчика. Решения ещё не утверждены.

## Пожелания заказчика

- Анимации переходов между страницами **не нужны**.
- Нравится, как у Exlipse: «видео с человеками и анимация» (на деле это 3D-модель в реальном времени, см. ниже).
- Dragonfly — «идея прикольная».

## Референсы

### Exlipse (exlipse.dev) — прямой конкурент

- Технически: Vite-SPA, three.js r169 (6 canvas), плавная прокрутка Lenis. **Видео нет**: «человек» — 3D-модель в WebGL.
- Шрифты: Inter Tight Variable (заголовки и текст), Geist Mono (подписи, метки, цифры).
- Палитра: светло-серый фон (#EDEDEB-подобный) и чёрный, секции чередуются, у светлой секции скруглённый верх «наезжает» на тёмную. Цветные акценты только в логотипах сетей.
- Заголовки огромные, капсом, жирное и тонкое начертание в одной строке («THE REASON *UNDERNEATH.*»).
- Hero: «WHY THE TOKEN MOVED» во весь экран и хромированный 3D-узел, который можно тянуть мышью («DRAG THE KNOT»).
- Секция 01: низкополигональная тёмная голова; при прокрутке распадается в облако точек и осколков.
- Секция 02 («Case file»): график цены на сетке, карточки улик (Smart money −95 с, Post on X −40 с, Migration −12 с, KOL buy +4 мин) с линиями к точкам графика, штамп «NO VERDICT», шкалы уверенности HIGH/MEDIUM/NOT A CAUSE.
- Секция 03: изометрический 3D-остров, по реке плывут монеты сетей.
- Дальше роадмап с датами, CTA «Open the feed», CA токена в шапке.
- Кнопки и бейджи — «пилюли».

### Dragonfly (dragonfly.com) — венчурный фонд

- Технически: three.js r179, Lenis. Видео нет.
- Главная идея — **ASCII-графика**: 3D-стрекоза, отрисованная символами, летает по экрану; превью статей тоже ASCII-рендеры (вихрь, здание).
- Палитра: чёрный фон, ярко-оранжевый акцент (≈#FF4F17), белый текст.
- Шрифты: гротеск NON Natural Grotesk (огромный вордмарк), антиква FK Roman Standard (основной текст), моно NON Natural Mono (метки `SEC-01`).
- Детали: буквы D/F/L/Y по углам экрана, плавающая мини-панель навигации по центру сверху, нумерованные секции «01 ABOUT», размытая крупная антиква («SINCE DAY 1»).

### Фото 01.tech (4 шт.)

- Светлый минимализм: серый фон, стеклянные карточки уведомлений поверх моноширинного текста, крупная гротескная типографика, портреты-вырезки на фоне гигантских цифр «01».

### Видео (IMG_1904–1906)

- 1904 «Astra + Opus · Spider brain»: чёрный фон, белая и розовая молния/пауки на поле линий, снизу панели с графиками и счётчиками стоимости.
- 1905 «REA / Reverse engineer anything»: радиальный дашборд, по кругу цветные панели (пайплайн, кривые, тепловые карты), счётчик в центре.
- 1906 «prompt-graph»: облака точек-кластеров разного цвета (objective, context, roles, rules, review), фокус перелетает между ними; снизу панель с метриками, радаром и круговым индикатором.
- Общее: тёмные data-viz интерфейсы «как терминал», много мелкого моно-текста, свечение, частицы.

## Что из этого подходит Kairos (предложение)

1. **Тёмная база + один акцент**, моно-шрифт для данных. Светлые секции — по желанию, как у Exlipse.
2. **Hero с 3D в реальном времени** вместо видео: фигура человека («шиллер») из точек или ASCII. Это объединяет оба любимых референса. Модель — готовый GLB (сток или заказ), рендер через three.js.
3. **Граф «шиллер → токен» как кластеры** (идея из IMG_1906): KOL — узлы, токены — точки, цвет — исход (успех, раг). Годится и для лендинга, и для дашборда.
4. **Карточка сигнала** в духе Case file у Exlipse, но про будущее: кто уже внутри, на какой минуте, на какие прошлые паттерны похоже, шкала уверенности, «не финансовая рекомендация».
5. Без анимаций переходов между страницами. Анимация внутри страницы (3D, реакция на прокрутку) — уточнить у заказчика.

## Решения (18.10.2026)

- Hero — «кластер-сигнал»: облака точек-шиллеров, к новому токену тянутся линии, вспыхивает сигнал (идея IMG_1906). Без 3D-модели человека, вопрос о её покупке снят.
- Акцент — оранжевый ≈#FF4F17.
- Основа тёмная, 1–2 светлые секции («Как это работает», «Роадмап») со скруглённым верхом, как у Exlipse.
- Анимация внутри страницы при прокрутке — да, активная (сцена hero реагирует на прокрутку, блоки собираются при появлении). Переходов между страницами нет. При системной настройке «уменьшить движение» — статичный вариант.
- Шрифты: Inter Tight (текст и заголовки), Geist Mono (данные и метки). Язык сайта — английский (решение 18.10.2026; русский как второй язык — возможно позже).
- Лендинг: `web/` (Next.js 16 + Tailwind v4 + three.js).
