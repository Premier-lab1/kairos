# Kairos showcase

Screenshots of the live service: the landing page at [xkairos.io](https://xkairos.io) and the open dashboard at [xkairos.io/app](https://xkairos.io/app) (no login). Captured on 2026-10-22 with [`scripts/screenshots.mjs`](../scripts/screenshots.mjs). The landing page uses demo data (it says so on the page); the dashboard shows real, live data.
